## 3. Section usage evidence (drives simplification decisions)

Sections that are **actually rendered** today (Dabba Rush, Umbrella Man, Elevator Empire) use only:
image sections with layout "auto" and text "top" (5), legacy image sections without a `kind` (11),
and one vertical card list (1). **No rendered section uses** path/range cards, tables, boards,
dividers, torn edges, tones, heading styles, chips, ornaments or presets — those appear only in the 17
hidden Whispers-of-Mahua sections stored on Songs of Saaja.

## 5. Export / restore

- **Full backup (recommended before any rebuild step touching data):** stop the dev server, then copy
  `.data/db.tar.gz` **and** `storage/uploads/` (and `.env.local`) to a dated folder outside the project,
  or zip them. Database and uploads must be backed up together — the database points at upload files.
- **Restore:** stop the server, put the saved `db.tar.gz` back into `.data/` (and the uploads folder),
  start the site. `REPAIR-DATABASE.bat` / `npm run db:repair` restores the newest *working* backup
  automatically if the live file is unreadable.
- **Read-only inspection:** load the file in memory (see CLAUDE.md §1).
- **Portable export:** the public API (`/api/v1/projects`, `/posts`, `/collections/*`, `/settings`)
  returns published content as JSON; drafts, users and media metadata need a database-level export
  (not yet scripted — candidate task).
